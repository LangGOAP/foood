# Contracts

`delivery-plus-public.json` is the generated public OpenAPI contract of the
[Delivery Plus](https://github.com/Delivery-Plus0/delivery-plus) backend (MIT, see
`LICENSE.delivery-plus`), pinned to commit `3f74caa3e2263279386383c741bbe1260cafcf05`. `foood` implements the
subset of it that the Delivery Plus apps call; `CONTRACT.md` at the repository
root lists which operations are implemented.
